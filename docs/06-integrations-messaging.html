03网关与路由

  • retail-route-center：规则路由决策，输出路由头 x-route-target-service-kind（xlb/wc）与 x-route-target-environment（prod/gray）；网关仅读头转发，不理解业务规则。规则可导出 DSL 给微信/POS/Qt/Java/TS 客户端运行时；但 POS Qt 端 v2.1 起本地求值、不再上送路由头（发送被注释、周期拉取 #if 0，见文档 19）。
  • retail-thirdpart-gateway：出站统一代理 POST /api/v1/proxy/:channel_id + 入站统一回调 ANY /callbacks/:channel_id/*；通用签名支持 HMAC-SHA256/MD5/组合，新 SaaS 渠道可配置化接入。
  • Istio Gateway-API：K8s 层入口，HTTPRoute + 金丝雀 + baggage-header lane + WASM 限流。
  • bff-gateway（GitOps retail-platform）：BFF 层网关（含快手变体）。
