03构建 · 发布 · 环境切换环境纯编译期宏 · 无 CI · Inno Setup 打包

  • 环境切换没有运行时配置：IS_ONLINE_VERSION 由构建机上的 D:/build-online.txt（MSVC）或 /tmp/online 决定； /tmp/wanchi 切万驰版（IS_BUILD_WANCHI_VERSION）；版本号走 VERSION_STR 环境变量，默认 0.0.1。 基址在 apiutil.h:27-37 以宏写死：xlb-pos-bff.retail-bff.ali-{prod,test,dev}.xlbsoft.com，万驰版 pos-bff-wanchi.*。
  • 打包：Inno Setup（ISCC.exe xlb-pos-qt.iss），.iss 不在仓内；后置步骤 install_depends_for_windows.bat 拷贝 Qt DLL / AI_SDK / VC 运行库。
  • 无 CI：仓内无 .gitlab-ci.yml / Jenkinsfile；batFile/ 是开发者 git 快捷脚本，build/windows/build.py + config.bat 承担半自动构建，厂商开关 POS_QT_BUILD_VENDOR。
  • 双构建体系：qmake 才是发布路径（还编 posscreen/posai/posalitouchpay/posUpdater 等辅进程），根 CMake 只产出 posclient；两套并存属遗留债。
