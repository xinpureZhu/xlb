04可观测性与工程约定

  • Tracing：全栈统一 OpenTelemetry OTLP → opentelemetry-collector.observability:4317；Java 用 javaagent，Rust 用 init-tracing-opentelemetry，Node 用 --import ./dist/otel.js。
  • Metrics/Logs：Micrometer/Prometheus + VictoriaMetrics / VictoriaLogs + Grafana；logs-monitor 做路径覆盖率巡检。
  • API 文档：Java 用 knife4j/springdoc；Rust 用 utoipa + Swagger UI；Node 用 knife4j 风格 swagger。
  • 错误监控：RN 端接入 Sentry。
  • DTO 映射：Java 广泛使用 MapStruct；工具库 Hutool / Guava / fastjson2 / Lombok。
  • 代码智能：oms-plateform / bff_pc / bff_pos 接入 GitNexus（代码图谱、影响分析、安全改名），对应 agents.md 为其配置文件。
  • 包管理/构建：Java=Maven；Rust=Cargo（rsproxy.cn 镜像）；Node=pnpm 9.15；小程序=pnpm+Taro CLI。
  • 基础镜像：阿里云 ACR zc_xlb/*（openjdk-21/8-arthas、jdk25-mvn、rust-1.88/1.93、node-22/23-slim）。

05值得注意的技术选型

  • Rust WASM：会员动态码与优惠计算编译为 WASM 供小程序端复用（coupon-assembly / member-assembly）。
  • GraalVM 原生镜像：oms-adapter 以 native image 部署，冷启动快。
  • AI 能力：oms-search 用 langchain4j + 通义千问(Qwen) 实现自然语言→SQL 订单查询。
  • 状态机 / TCC：oms 用 COLA 状态机；营销活动与订单用 TCC（Try-Confirm-Cancel）保证跨服务一致性（Seata 已引入但禁用）。
  • Module Federation：RN 微前端在 App 侧落地，远程 bundle CDN 分发 + 按 userId 灰度。
  • 虚拟线程 + ZGC：Java 25 服务（goods、oms）启用虚拟线程与 ZGC。
