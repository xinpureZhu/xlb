01Java 业务中台 Java / Spring Boot

项目版本职责可部署单元 / 模块
retail-new Boot 3.3 / Java 21 新零售微服务聚合仓：会员、优惠券、储值/礼品卡、订单(OMS)、POS 结算、营销/任务、抽奖、拼团、短信、公益/福利、VIP。 52 个 Maven 模块。运行服务：retail-c/-api/-manager、member-c/-pos/-manager、oms-c/-manager、marketing-c、sse-server、cron-server、group-c、member-sms、retail-pos-item-initialization、store-near；+27 个 MQ 消费者（会员/卡券/优惠券/订单/POS/抽奖/福利/VIP 同步）。端口 55110。
retail 遗留 Boot 2.7 / Java 8 门店 ERP-POS 单体：商品/SKU/条码/分类/品牌、门店/仓库、POS 收银机与订单、价格与电子价签、调价、促销、库存、采购/配送/供应商、结算、诺诺发票、用户权限。 单一 jar（~1835 java 文件）。JPA+QueryDSL、RabbitMQ、xxl-job。端口 55131。
xlb-retail-bff-goods 新 Boot 3.5.6 / Java 25 门店商品库存服务（xlb_retail_bff_pc 的 Java 迁移版，业务能力一致）：商品/SKU、分类、门店商品关系、库存/价格、渠道、电商/外卖商品、积分商品、标签、首页搜索。 10 模块。运行：goods-b(18080) + 6 个 Kafka 消费者（takeaway/price-dts/task-sync/es-product/store-relation/dfp）。MongoDB + ES + Redisson。
marketing-activity-center Boot 3.4.5 / Java 21 营销活动编排中台：活动主数据、范围/资格、生命周期、补发入口；抽奖/兑奖/任务/指标/榜单/虚拟资产下沉到下游。活动类型：刮刮乐、打榜、会员日蓄水抽奖、新人抽奖、定时开奖、问卷。 ~1500 java 文件。分层 core→base→ext→app→deploy + dal/soa-client/infra。部署：admin(55142) + player(55143)。
oms-plateform 新/部分完成 Boot 4.0 / Java 25 订单管理中台（DDD）：接入三方渠道（美团闪购为主）、订单生命周期、履约、逆向、结算、检索。COLA 状态机 + TCC。 模块：oms-adapter(55199, GraalVM 原生镜像入口)、oms-core(55188)、oms-fulfillment、oms-reverse、oms-search(8084, ES+Qwen NL→SQL)、oms-settlement、oms-common、oms-starter。
注意 oms-plateform 的 README/集成文档版本信息滞后（写 Java 21/Boot 3.x/MyBatis-Plus），以 pom.xml 为准（Java 25/Boot 4.0/MyBatis-Flex）；且 fulfillment/reverse/settlement/search 多为骨架，adapter+core 为实体。

02Rust 高性能服务 Rust / axum

项目职责存储/消息可部署单元
rust-for-order 优惠券与促销计算引擎、会员动态码（含小程序 WASM）、POS 订单持久化、SSE 推送。 MySQL(pos-order)、Redis coupon-web(3000, 主二进制)、member-web、pos-order、rust-sse-server + WASM 组件(coupon/member-assembly)。
goods_cart 多渠道购物车（增删改查/选中），纯 Redis 存储。 Redis 单二进制（3009）。
goods_consumer ERP 库存 & 商品主数据同步到商品平台：Kafka 库存明细批处理 → Redis(Lua) + MongoDB，产出售罄状态事件；RocketMQ 监听商品类型变更。 Redis + MongoDB / Kafka + RocketMQ erp_stock_sync、mps_item_change_sync。
icc-task 企微(ICC) 群发/朋友圈任务看板：本地查询、定时同步、异步 XLSX 导出、补偿、限流、组织权限过滤。namespace scrm。 MySQL + Redis + OSS / Kafka api(8080)、sync-worker、export-worker、scheduler（同镜像 4 单元）。
retail-route-center 规则路由决策中心：决策自研(xlb)/遗留(wc) 与 prod/gray，导出 DSL 给多端客户端。 MySQL + Redis(PubSub) + OSS public / admin / all（按 APP profile）。
retail-thirdpart-gateway 第三方 SaaS 统一网关：签名、回调验签+转发、出口治理、可观测。接入美团闪购、飞鹅打印。 MongoDB + Redis（无 MQ，直连出站） public / admin / all（3000）。
rs-gray-ms 前身 灰度名单服务：手机号/后缀判定灰度；产出小程序灰度配置上传 OSS。 MySQL(PolarDB-X) + OSS 单二进制。
retail-review-center 新增 商品评价中心（一期）：评价资格、商品与门店评价、首页待评提醒、订单完成/退款事件消费、后管标签星级配置与统计。详见 16 篇。 MySQL + Redis / RocketMQ 6 crate DDD 分层；review-c（C 端）+ review-b（后管）+ review-worker（一个二进制 7 种角色：order-consumer / expire / event-publisher / stat / compensation / risk / notify）。31 张表。

03NestJS BFF 与服务 Node / NestJS 10

项目服务端主存储职责
xlb-mp-bff 活跃小程序 / H5 (MINIPROGRAM)Redis + ES（无自有 DB）会员 C 端 BFF：登录、会员中心、卡券、积分、商城/拼团/官方商城下单、营销/抽奖/公益、支付；~40 个下游服务、同盾风控、灰度。
xlb_bff_retail 遗留孪生小程序 (MINIPROGRAM)Redis + ESxlb-mp-bff 的旧版孪生；新版增加 marketing-activity-player、member_assets_es_v2 等。
xlb_retail_bff_pc 遗留PC 商家后台 (XLB_PC)MongoDB + ES + Kafka门店商品库存服务：商品/目录主数据、门店商品关系、库存、价格、ERP↔平台数据同步。正被业务能力一致的 Java 版 xlb-retail-bff-goods 替代。
xlb_retail_bff_posPOS 收银机 (POS_MACHINE)MySQL (TypeORM)收银结算、班次、库存、价签、折扣码、门店会员操作；本组唯一以关系库为主库。
cms-serverPC 商家后台 (XLB_PC)MongoDB + ES + Bull小程序装修/页面配置、营销落地资产、空白二维码、企微活码、关联投放链接。iAuth 权限校验。
auth-server平台内部Redis + node-cache第三方平台 Token 代理（微信/支付宝/快手/抖音/美团点评/乐檬），无 DB、无 RBAC。端口 3005。
mall-mcp 骨架（规划中）内存 mock「对话下单」MCP 设计骨架：定义 8 个工具契约，尚未接入真实 MCP SDK/上游。
