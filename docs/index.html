00平台一览

XLB（新零帮）是一套面向连锁零售的 SaaS 中台，覆盖商品、库存、门店、POS 收银、会员、卡券、营销活动、订单履约、结算对账等全域能力。 系统由多技术栈微服务 + 多端应用组成：Java（核心业务与中台）、Rust（高性能网关/计算/消费者）、NestJS（各端 BFF）、React Native（App 微前端）、Taro（小程序）， 统一由 ArgoCD + Jsonnet 的 GitOps 体系部署至阿里云/腾讯云 Kubernetes 集群。
