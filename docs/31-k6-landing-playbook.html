01结论与落地口径 落地的定义是「部署后自动跑业务冒烟、失败即阻断、结论可追溯到 sha」，路线 C 是主线

结论：k6 落地不需要新平台，也不需要等平台排期。执行面（k6-operator）、编排面（Argo 环境子流程 + 模板生命周期 API）、观测面（VictoriaMetrics + vmalert + alert-webhook）三面都已存在，缺的只是把它们接起来：一个自包含的冒烟节点 + 一个自带 git/kubectl/jq/k6 的 runner 镜像 + 一条 RBAC + 一份服务仓 perf/ 契约。这四件套就是「落地」的全部新建物。
4新建物：节点模板 / runner 镜像 / RBAC / perf/ 契约（其余全是复用）
0需要改的平台 Go 代码（路线 C；接入走模板与流程的配置 API）
3结果消费处：DAG 阻断 / VM 指标与告警 / 报告归档 + 节点回写

四条落地口径（决定「做对」还是「看起来做完了」）：

  1. 判定在部署之后、人工审批之前：插入点是环境子流程 cd 之后的独立节点。不能再借人工审批节点做「自动通过」——审批放行走私有鉴权路由，公开的 /workflow/node/* 不校验审批状态，等于把门禁开放给任何集群内进程。
  2. 用例的唯一归属是服务仓 perf/：脚本、阈值、场景元数据随接口同 PR 演进；gitops 只留「服务 × 环境 × 套件」开关，不再承载脚本正文。禁止引用浮动分支。
  3. 编排与判红下沉到集群侧自包含节点（路线 C）：S0–S7 全部在节点 Pod 内完成，平台只收 /node/start 与 /node/complete 两个通用回调。发布单引用冒烟记录是增项（路线 P），不作为一期目标。
  4. 无数据即失败（no_data = fail）：缺脚本、环境不可达、requests/cases 计数为 0 一律判红。这条口径独立于已有的质量门禁语义（「阈值未配置 = 不检查」），必须单独实现，否则会出现最危险的假绿。
反向结论（不要做）：① 不要在服务仓的 CodeUp 流水线里跑冒烟当作门禁——那是构建期，看不到本次部署结果；② 不要为冒烟新建独立测试平台——执行、编排、观测三面都已存在；③ 不要用浮动分支或 PVC 共享脚本（结论无法回答「这是哪个 commit 的用例」）；④ 不要在 prod 跑写路径冒烟或用 k8s CronJob 做 prod 巡检（cronJobMode 在 prod && version>=136 硬编码为 off）；⑤ 不要把 UI 断言塞进 k6，也不要禁用 k6 deps 依赖门禁去引 xk6 自定义构建。

3已否定（不用）

xk6 自定义构建（依赖门禁直接拒绝，会引入镜像分发问题）；k6 官方浏览器模块（UI 场景交给已有 UI 自动化，k6 留在协议层）；Grafana Cloud k6（数据出境与网络可达性无必要）。

4已否定（不用）

PVC 共享脚本（版本不可信，仅本地调试）；每服务一个 k6 仓（评审与治理成本爆炸）；脚本改用 Node/Python 重写（原生 TS 已经够用，多一套工具链只增加维护面）。

operator 的两个实测坑（照抄，别重复踩）：① starter 命令由 operator 固定生成 sh -c "curl …"，官方 grafana/k6 镜像里没有 curl，starter 必须用带 curl 的镜像（现成可用 gitops-tools/curl:jq-latest）；② spec.arguments 在 CRD 里是字符串，operator 原样塞进 runner argv，带引号的参数（如 summaryTrendStats）会被当成单个 trend stat 导致启动失败 ⇒ 这类参数写进脚本，环境相关值走 env/envFrom（cart-list-test.js 顶部注释即此结论的现场记录）。

09风险与红线 最可能的失败不是技术，而是门禁被噪声淹没

风险机理处置
冒烟噪声化（最可能失败的模式）环境不稳/数据缺失导致频繁误红，团队开始忽略门禁一次重试 + 隔离清单 + 先跑 env-gate；门禁先告警期 2 个迭代再硬阻断
写脏数据冒烟真实写入并触发下游 MQ 与风控专用账号 + 幂等键 + teardown 清理；prod 只跑只读探活
共享环境互扰test/staging 多需求共用，冒烟与被测部署互相影响环境级互斥锁；同环境同时间只跑一个套件
门禁 fail-openportal 异常兜底 passed=true；阈值未配置＝不检查「配置了但无结果＝失败」独立分支；定期核对「通过但无明细」
误把冒烟当回归套件膨胀到几百条，部署被拖住硬性时长预算 + 集分层（service-smoke / env-gate / 回归集分离）
版本族漏插v1–v5 + hotfix + redeploy 共存，只改一个插入点清单化，验收逐文件核对
凭据散落冒烟账号/Token 被写进 300 个服务仓只走集群 Secret + envFrom；脚本只读 __ENV
