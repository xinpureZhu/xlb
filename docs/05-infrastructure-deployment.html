01GitOps 工具链

部署体系 = ArgoCD（引擎）+ Jsonnet（模板）+ Argo Rollouts（金丝雀）+ Istio/Gateway-API（网络）+ Pulumi（云 IaC）。非 Helm、非 Tanka，是自研 Jsonnet 框架，由 argocd-repo-server 渲染。

组件路径作用
ArgoCDapps/argocd/apps.jsonnet每命名空间生成一个 Application；prod 集群跟 prod 分支、其余跟 test 分支；自动 prune + selfHeal。
Jsonnet 引擎apps/templates/Compose.libsonnet读取命名空间的 *.app.yaml + artifacts.libsonnet 镜像 tag，解析按环境取值、IAC 密钥引用、服务 DNS、金丝雀展开。
对象模板apps/templates/App/*.libsonnet为每服务生成 Rollout/Deployment、Service(+canary)、Istio DestinationRule、Gateway-API HTTPRoute、HPA、ServiceAccount、PDB、AuthorizationPolicy、VMServiceScrape。
Argo Rolloutsapps/argo-rollouts/默认工作负载为 Rollout，Istio/Gateway-API 金丝雀流量切分 + AnalysisTemplate(istio-success-rate)。
Pulumiapps/pulumi/Pulumi.*.yaml云基础设施：OSS、RDS/PolarDB、Redis/Tair、MongoDB、Kafka、RocketMQ、RAM、ES；输出以 IAC__{NS}__{INSTANCE}__{KEY} 注入服务。
apps/clusterName.libsonnet 是当前 checkout 渲染目标集群的唯一真源（如 ali-test）。apps/eval.sh 本地渲染、apps/init.sh 引导新集群（强制 env == clusterName == kubeconfig 三方一致）。

04工作负载配置模式

每服务在 *.app.yaml 中按环境声明 minReplicas/maxReplicas/hpaCpuAverageValue/resources/port/healthCheckEndpoint/enablePublicAccess*。两个实例：

goods-wanquan (pc-bff-wanquan) · port 3001 · /health/readiness
prod 10–80 副本、test/staging 2–4、gray 1；HPA CPU 0.3；limits 1c/4Gi、requests 0.2c/300Mi；prod 开 podAntiAffinity；附 5 个 CronJob。
retail-thirdpart-gateway (Rust) · port 3000 · /health
test 2 副本、dev 1；HPA CPU 1；limits 1c/2Gi、requests 0.4c/1Gi；dev~prod+gray 全环境；公网 host 开启。
  • HPA：每服务生成，单一 CPU AverageValue 指标。
  • Ingress：enablePublicAccessWithDefaultHostName: true 时生成 Gateway-API HTTPRoute，网关 ingressgateway.istio-system。
  • 金丝雀：Rollout + Istio/Gateway-API 流量切分 + baggage-header lane 路由 + WASM 限流。

05可观测与通知

  • Tracing：OpenTelemetry collector（opentelemetry-collector.observability:4317），由 Workload.libsonnet 注入每个工作负载。
  • Metrics/Logs：VictoriaMetrics/VictoriaLogs、Grafana、Prometheus exporter、阿里云 ARMS。
  • 巡检：logs-monitor（Python）查 Grafana→VictoriaLogs 的 Istio sidecar 访问日志，统计预设 API 路径覆盖率，推送飞书交互卡片（全覆盖绿色✅ / 缺失橙色⚠️）。当前监控 retail-gateway 的美团回调端点。
  • 通知：各命名空间飞书 webhook（info / alert 两类），另有 gitops web 看板。
安全提示 gitops 的 *.app.yaml env、envs.libsonnet、1compose/*.yaml 及 logs-monitor 的 .env 含真实数据库/Redis/Kafka/MQ 凭据与密钥。本文档仅描述结构，不复制任何密钥值；操作时勿将其写入文档或提交到非受控位置。
