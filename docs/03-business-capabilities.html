01商品 / 库存域

主责：xlb-retail-bff-goods（门店商品库存服务，Java 迁移版，MongoDB/ES）、xlb_retail_bff_pc（同一服务的遗留 Node 版，业务能力一致）、retail（ERP 商品主数据）、goods_cart、goods_consumer。

能力说明归属
商品/SKU 管理商品创建/编辑/详情/列表、条码、组合商品、多规格。goods-b、retail(Item)
分类与目录ERP 分类、目录树、商品-目录关系、排序。goods-b(Category/Catalog)
门店商品关系门店-商品关系维护、批量改价/上下架/库存、门店商品汇总报表。goods-b(StoreProduct)、pc-bff
渠道商品电商商品、外卖商品（导入导出、批量上下架）、积分商品、官方商城商品。goods-b(ECommerce/TakeAway/Point)
库存同步ERP 库存明细 → Redis(Lua) + MongoDB，跨渠道可售量重算（官方/积分/美团/淘宝/京东/viola），售罄事件下发。goods_consumer(erp_stock_sync)
价格 / 电子价签零售价模板、门店零售价、固定价、价签任务、官方门店零售价 DTS 同步。retail(PriceTag)、goods-b、price-dts 消费者
购物车多渠道购物车增删改查/选中，Redis 存储。goods_cart(Rust)
商品搜索官方商品 ES 索引同步与检索、首页搜索。es-official-product 消费者、goods-b(HomeSearch)

02会员 / 卡券域

主责：retail-new（member-c / member-pos / member 模块，最大域）、xlb-mp-bff（C 端聚合）、rust-for-order（会员动态码）。

能力说明
会员会员基础、等级、渠道、VIP 卡、会员码（Rust 时间片动态码 + 小程序 WASM）。
优惠券券类型/批次/领券中心/组合券/直发券/平台券/额度券/微信商户券/支付宝商户券；发放、核销、反核销、同步。
储值卡卡类型、充值(deposit)、消费、退款、交易流水、储值权益、充值活动。
礼品卡类型/分类/面额/祝福语/购买订单/交付明细/制卡/操作员；购买、领取、退款、历史。
积分积分账户、兑换、积分商城、积分变更管理（App 端 remote-app-mem）。
权益 / 榜单充值活动、充值权益、榜单(含券榜)。
发票发票抬头、开票历史；ERP 侧诺诺电子发票。
公益 / 福利「好想做公益」项目/明细/进度/捐赠规则/机构/三方 API；福利下单与延迟同步。
三方会员抖音/快手 会员+券同步、支付宝门店、微信私域活动绑定。

03订单 / 履约域

主责：retail-new(oms 模块)、oms-plateform(订单中台)、rust-for-order(POS 单/优惠计算)。订单类型覆盖：积分兑换/卡/POS/美团闪购/淘宝闪购/京东秒送/线上商城/拼团/京东电商/淘宝/拼多多。

能力说明归属
下单与计算订单创建、金额计算、优惠/促销计算、积分支付、XPay 支付；TCC 分布式事务（库存/卡/券/VIP/拼团）。retail-new/oms、rust-for-order/coupon-web
订单生命周期COLA 状态机：TO_PAY→PAID→CONFIRMED→FINISHED / CANCELED，部分退款。oms-plateform/oms-core
逆向 / 退款退款单、退款明细（门店/平台承担）、退款交易记录；仅退款 / 退货退款。oms-reverse、retail-new(RefundOrder)
履约自提单、同城单、物流发货。oms-fulfillment、retail-new(Pickup/SameCity)
渠道接入美团闪购回调（下单/支付/接单/完成/取消/配送）验签→标准化→入核心。oms-adapter、retail-thirdpart-gateway
订单检索ES 宽表读模型 + Qwen 自然语言→SQL 查询。oms-search
拼团开团/成团、支付超时、回调重试。retail-new/group

04POS / 门店域

主责：retail（ERP-POS 单体）、retail-new(retail-c/-api/-manager、pos-item-initialization)、xlb_retail_bff_pos。

能力说明
POS 收银收银机管理/版本/推送、POS 订单/明细/快照、结算单/支付/券、班次(Shift)、小票模板、副屏、AI 激活码、事件日志、异常操作分析。
结算POS 结算单、支付、结算券处理，结算已支付回调。
促销特价/金额折扣/多买优惠/赠品/折扣码/商品模板/政策活动（retail 单体 promotion 插件）。
调价门店零售调价单、门店调价申请单、调价汇总。
门店主数据门店、门店组、仓库、区域、门店费用、公告、经营补贴。
盘点 / 库存盘点单、库存查询/调整（App remote-app-erp）。
采购供应链采购订单/收货/退货、配送调入、供应商、批发订单、补货（remote-app-erp）。
商品初始化POS 商品/价格/门店主数据初始化下发。

05营销 / 活动域

主责：marketing-activity-center（编排中台）、retail-new(marketing/lottery/group)、xlb-mp-bff(C 端玩法)。

能力说明
活动编排活动模板/表单设计、B 端配置与生命周期（保存/激活/终止/续期/删除 + 热修改）、C 端参与（欢迎/抽奖/任务/榜单）。基于 Pipeline+Step+TCC。
活动类型刮刮乐、苏超打榜、会员日蓄水抽奖、新人抽奖、定时开奖、问卷调研；签到、阶梯任务、兑实物、兑换券。
抽奖抽奖客户端/市场/明细/兑换/统计/补发/日志/地址/预约/退积分；小满(XiaoMan)抽奖变体。
任务任务管理/明细/进度/奖励、消费任务、邀请裂变绑定与奖励。
榜单 / 虚拟资产榜单 CRUD/激活/助力/实时+历史排名（RocketMQ 事件上报）、热力值等虚拟资产扣减/发放。
下游能力兑奖引擎、抽奖引擎、营销指标(参与限制)、会员积分、门店/用户组范围、ICC 企微校验（11 个 SOA 子系统）。
